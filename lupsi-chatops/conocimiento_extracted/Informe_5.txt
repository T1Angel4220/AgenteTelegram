1.  Título
Informe de inicialización de frontend Angular como PWA base con SCSS/Tailwind
2.  Introducción
El frontend del sistema LUPSI se construye con Angular, configurado como una
Aplicación Web Progresiva (PWA) para ofrecer experiencia similar a una app nativa
en dispositivos móviles. Este informe documenta la creación del proyecto, la habili-
tación del service worker, la integración de SCSS y Tailwind CSS, y el estado actual
del desarrollo hasta la fecha de presentación (08/09/2025).
3.  Objetivo
Disponer de una base de frontend funcional, responsive, con capacidades offline
básicas (PWA) y una estructura de estilos moderna que acelere el desarrollo de las
próximas historias de usuario.
4.  Definiciones
Angular: Framework de desarrollo frontend basado en TypeScript.
PWA (Progressive Web App): Aplicación web que utiliza tecnologías mo-
dernas para ofrecer una experiencia similar a una app nativa (instalable, offline,
notificaciones).
Service Worker: Script que actúa como proxy entre el navegador y la red,
permitiendo cacheo y funcionamiento offline.
Tailwind CSS: Framework CSS utility-first para diseñar interfaces rápida-
mente.
5.  Actividades realizadas
Creación del proyecto Angular con Angular CLI: ng new frontend-lupsi
–style=scss –routing.

Prueba de funcionamiento offline y capacidad de instalación en dispositivo
móvil.
6.  Herramientas utilizadas
Angular CLI 17
Node.js v20
Visual Studio Code
Chrome DevTools (modo dispositivo, auditoría PWA)
7.  Resultados obtenidos
Proyecto Angular funcional con comando ng serve.
Aplicación instalable en Android y Chrome Desktop (opción "Instalar app").
Service worker activo que cachea los assets estáticos.
Estilos base con SCSS y Tailwind: paleta de colores corporativa definida.
Estado a fecha 08/09/2025: 80 % completado. Pendiente ajuste de rutas
dinámicas, pruebas completas de PWA en diferentes navegadores y generación
de build de producción.
