1.  Título
Informe de Configuración de Repositorios (GitHub) y Entorno Base (Docker).
2.  Introducción
Este informe documenta la culminación técnica del Sprint 1 del proyecto LUPSI.
Una vez validados los requerimientos, los prototipos visuales y el modelo de base de
datos, el paso final previo a la codificación (Sprint 2) es la preparación del entorno
de trabajo colaborativo. Este documento certifica la creación de los repositorios de
control de versiones y la estructuración de las ramas de desarrollo.
3.  Objetivo
Establecer una base de control de versiones centralizada, segura y ordenada (Git-
Flow), junto con los cascarones de configuración inicial (Docker), garantizando que el
equipo de desarrollo cuente con la infraestructura necesaria para integrar su código
a partir del Sprint 2 sin conflictos ni bloqueos operativos.
4.  Definiciones
Control de Versiones (Git): Sistema que registra los cambios realizados en
los archivos del proyecto a lo largo del tiempo.
GitHub: Plataforma de alojamiento en la nube utilizada para centralizar los
repositorios del equipo.
GitFlow (Ramas): Estrategia de ramificación que separa el código en pro-
ducción (main) del código en desarrollo (develop).
Docker: Plataforma de contenedores que empaqueta el software y sus depen-
dencias para garantizar que funcione uniformemente en cualquier equipo.
5.  Actividades realizadas
Creación de los repositorios oficiales para el proyecto en la plataforma GitHub.
