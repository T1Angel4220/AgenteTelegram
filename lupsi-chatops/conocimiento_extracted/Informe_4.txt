1.  Título
Informe de inicialización de backend NestJS con Docker y despliegue en Render
2.  Introducción
El backend del sistema LUPSI se desarrolla con el framework NestJS, que pro-
porciona una arquitectura modular y escalable. Este informe cubre la creación del
proyecto base, su contenerización con Docker, la conexión a Supabase y el despliegue
inicial en la plataforma Render.
3.  Objetivo
Contar con una API funcional, ejecutable en cualquier entorno mediante Docker,
y disponible en la nube (Render) para ser consumida por el frontend y realizar
pruebas de integración tempranas.
4.  Definiciones
NestJS: Framework de Node.js para construir aplicaciones del lado del servi-
dor eficientes y confiables.
Docker: Plataforma de contenedores que permite empaquetar aplicaciones
con sus dependencias.
Render: Servicio de nube utilizado para desplegar el backend de forma gra-
tuita en un entorno de prueba.
5.  Actividades realizadas
Inicialización del proyecto NestJS con el CLI oficial: nest new backend-lupsi.
Configuración de módulos básicos: AppModule, controlador de salud (health).
Instalación de dependencias: @nestjs/config, @nestjs/typeorm, typeorm,
pg, @supabase/supabase-js.
